# Hotel Billing Program

A C++ console application that calculates the total cost of a hotel resort stay based on room price, number of rooms, and length of stay.

## Features

* Accepts the price per room
* Accepts the number of rooms being booked
* Accepts the number of days for the stay
* Calculates the room subtotal
* Calculates a 14% tax
* Calculates a $5 per-day, per-room gratuity
* Displays the final cost of the hotel stay

## How to Run

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Compile the program:

`g++ hotel_bill.cpp -o hotel_bill`

4. Run the program:

**Windows:**

`hotel_bill.exe`

**macOS/Linux:**

`./hotel_bill`

5. Enter the requested hotel stay information when prompted.
